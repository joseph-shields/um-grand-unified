## The structure

From φ² = φ + 1, with r = 1/(2φ) ≈ 0.30902:

```

W_B = 2r(1−r)      ≈ 42.71%   boundary · interface · coupling · FORCED, not chosen
W_L = (1−r)²       ≈ 47.75%   expanding · field · possibility · the open pole
```

W_B is never a third independent thing. It is the cross-term that cannot be absent when two poles exist under a degree-2 axiom. The interface is mandatory. Every field in this repo has a W_M, a W_L, and a W_B — and in every case the W_B is the thing that field has been trying to explain rather than derive.

## What "structural" means

Some results in these papers are marked DERIVED — they follow algebraically from the channel weights. Others are marked STRUCTURAL — the mapping is coherent and the framework is consistent, but the quantitative derivation requires additional work. Both are valuable. The structural results identify where the framework points; the derived results show it can be exact.
