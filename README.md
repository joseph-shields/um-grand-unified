## What this repo is

These are structural extensions — exploratory mappings of the UM framework onto fields outside physics. They are not derivations. They do not carry the same weight as the core UM corpus in [unified-mechanics](https://github.com/joseph-shields/unified-mechanics), which has 20 numerical results within the braiding floor, zero free parameters, and falsifiable predictions.

What these papers do: identify W_M, W_B, and W_L in each domain, show the mapping is coherent, and flag where the numbers are genuine vs where the structure is suggestive. Some have sharp numerical hits. Most are structural observations.

Think of them as: *here is where UM points when you look in this direction.* Not: *here is what UM proves in this domain.*

## The core structure (carried into every paper)

```
W_M = r²           ≈  9.55%    contracting · structure · the stable pole
W_B = 2r(1−r)      ≈ 42.71%   boundary · interface · FORCED by having two poles
W_L = (1−r)²       ≈ 47.75%   expanding · field · the open pole
ε_floor = r³       ≈  2.95%   minimum cost per channel traversal
```

W_B is never chosen. It is forced the moment two poles exist under a degree-2 axiom. Every paper identifies what W_B is in its domain — and in each case it turns out to be the thing that field most struggles to explain from first principles.

## The ones worth taking further

If any of these should graduate to proper UM derivations, it's these four:

- **Chemistry** — the DNA number is too close to be coincidence. Needs a full paper in unified-mechanics.
- **Genetics** — amino acid count from r² is clean and testable.
- **Game theory** — Nash equilibrium as UM fixed point is mathematically rigorous already.
- **Control theory** — PID stability as UM eigenvalue condition is already proven, not structural.

The rest are here because the framework points there, not because the case is made.
